# Location Tracker App

Aplikasi web sederhana untuk meminta izin lokasi pengguna dan menyimpan koordinatnya.

## Cara Menjalankan

1. Install dependencies:
```bash
npm install
```

2. Jalankan server:
```bash
npm start
```

3. Buka browser dan akses:
```
http://localhost:3000
```

## Fitur

- Meminta izin lokasi secara transparan menggunakan Geolocation API
- User harus menekan tombol dan menyetujui permission browser
- Koordinat disimpan ke file README.md ini
- Menampilkan link Google Maps langsung

## Catatan Penting

- Website ini hanya bekerja di HTTPS atau localhost
- User harus secara aktif memberikan izin lokasi
- Ini menggunakan API standar browser yang legal dan transparan
